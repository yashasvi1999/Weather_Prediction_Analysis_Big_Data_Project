# Weather_Prediction_Analysis_Big_Data_Project

### Overview

This project implements a Big Data pipeline for weather data analysis. It processes historical and daily weather data, performs preprocessing and transformations, and analyzes trends using PySpark. The workflow is automated using Apache Airflow.

### Technologies Used

- Python
- Apache Spark (PySpark)
- Apache Airflow
- CSV-based datasets
- Ubuntu (Linux)

### Pipeline Description

- Ingests historical and daily weather data
- Cleans and preprocesses raw data
- Processes data using Spark for trend analysis
- Orchestrates tasks using an Airflow DAG
